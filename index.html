Nobles Pit 2 Tile Server

GitHub Pages is working correctly.

This repository hosts XYZ map tiles for use in Leaflet.

Base URL:

https://pornzpower.github.io/Nobles_Pit_2/

Leaflet Example

L.tileLayer(
'https://pornzpower.github.io/Nobles_Pit_2/{z}/{x}/{y}.png',
{
    minZoom: 14,
    maxZoom: 22
}
).addTo(map);
